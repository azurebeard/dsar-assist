1 · The request

A ticket or file number, never the person's name: it is written to a permanent audit record and shown in the Purview portal.

The day the request arrived. The deadline is one calendar month from this date, recorded once when the case is created.

Why this matters

The statutory clock is one calendar month from receipt, not from when the case was opened, so the deadline is calculated from this date. Extensions and clock pauses are not modelled; the date shown is the baseline. The date is not editable here afterwards: to correct it, edit the case description in the Purview portal. Left blank, the deadline shows as not recorded rather than being guessed from the creation date.
